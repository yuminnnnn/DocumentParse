
# Docs 폴더 구조 안내

이 디렉토리는 프로젝트 결과물과 문서 파싱 초안을 정리하기 위한 공간

docs/<br>
├── draft/ # 문서 파싱 결과물 (최종 수정 전)<br>
├── final/ # 직접 검토 및 수정이 완료된 최종 완성본<br>
└── other/ # 테스트용 json 파일<br>

##  폴더 설명

- **draft/**  
  문서 파싱을 통해 자동 생성된 초안 파일들이 저장<br>
  아직 최종 검토 및 수정이 이루어지지 않은 상태


- **final/**  
  초안을 기반으로 직접 검토 및 수정을 완료한 최종 완성본이 저장<br>
  홈페이지를 직접 확인하고 작성한 내용 저장
